Cloud Picnic

Little clouds. Big smiles.

Slide picnic cushions, open paths, and help each cloud guest find a seat.

Cloud Picnic is a cozy puzzle game with 100 picnics across meadows, flower fields, and lantern-lit evenings. The first 10 picnics are free; one optional in-app purchase unlocks Picnics 11–100.
