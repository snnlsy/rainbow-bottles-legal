# App page folders

All Wibbi Wobbo app privacy and support pages live in this single GitHub Pages
repository under `apps/<workspace-id>/`. Each app has its own `privacy/` and
`support/` pages so its statements can be reviewed against that app's actual
behavior.

The directories for apps that are not yet prepared for publication are
scaffolds. Do not use them as App Store URLs until their app-specific pages have
been written and checked.
